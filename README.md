## 寫作規則

1. 一句一行：每寫完一句（句號、問號）就換行，Git 才能準確標出改了哪一句；兩段之間空一行。
2. commit 訊息寫「[章節編號] 做了什麼」，例如：`[01] 新增家鄉熱危害經驗`。
3. 圖片放在 `figures/`，檔名用英文小寫與底線，例如 `figures/idw_wbgt_14h.png`。
4. 原始資料不要上傳：放在 `data/` 的檔案已經被 `.gitignore` 排除。
5. 改別人的章節一律用 Pull Request，讓原作者決定要不要接受。
6. 審稿期間，作者先不要改自己的章節，避免和審稿人的修改衝突。
